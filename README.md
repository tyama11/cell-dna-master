# 細胞・酵素・DNAマスター 🧬

生物基礎・生物の重要テーマである「顕微鏡の限界・原核生物と真核生物・酵素の特徴」および「DNA塩基割合・シャルガフの法則・ゲノム・体細胞と生殖細胞」を、楽しいパズル形式とタイムアタックで直感的にマスターできる学習Webアプリです。

👉 **[アプリを遊ぶ (GitHub Pages)](https://tyama11.github.io/cell-dna-master/)**

---

## 🌟 主な特徴

- **2つの学習カテゴリ**
  - **🦠 原核・真核 ＆ 酵素**: 肉眼・光学・電子顕微鏡の解像度スケール、細菌類（原核）と菌類（真核）のちがい、基質特異性やカタラーゼ・ルシフェラーゼなどの代表酵素を整理します。
  - **🧬 DNA塩基表 ＆ ゲノム**: シャルガフの法則（A=T, G=C）に基づく2本鎖・片鎖の塩基割合計算、ゲノムの構成、体細胞（2n）と生殖細胞（n）のDNA量関係をマスターできます。
- **3つの選べる難易度**
  - 🔰 **かんたん**: アイコンやヒントを頼りに楽しく学習できます。
  - 🧪 **ふつう**: アイコンなしで正確な位置や名称を思い出しながら挑戦します（クリアで「おに」が解放！）。
  - 👹 **おに (60秒TA)**: 制限時間60秒のハードコアタイムアタック！5連続正解（コンボ）でタイムボーナス＋3秒、ミスするとペナルティ。称号ランク（S〜C）を目指そう！
- **キーボード対応 & 完全オフライン動作**
  - マウス操作だけでなく、タブ移動・エンター決定・「おに」モードでの数字キー（1〜3）によるクイック回答など、スムーズな操作性を実現しています。
